## MemeAim 3D Windows 版

- Windows 10 / 11 x64，可离线运行，无需安装 Python 或 Node.js。
- Gridshot、Tracking、Flick 三种 3D 训练模式，第一人称手持枪、枪口闪光与后坐动画。
- 18 段随机位置、随机大小的绿幕梗，6 种程序全屏动画和 5 段全屏视频特效；命中和打空都能触发。
- 训练参数、准星、音量、特效开关和本地成绩记录。
- 保留原 Python 版源码；移除占位文件 `mm`。

### 下载哪个文件？

- **Portable.zip**：免安装，完整解压后双击文件夹内的 `MemeAim 3D.exe`。
- **Setup.exe**：安装到电脑并创建快捷方式。
- **SHA256SUMS.txt**：下载文件校验值。

两个版本都包含相同游戏和离线素材。当前未做商业代码签名，Windows 可能显示未知发布者；需要支持 WebGL 2 的显卡与驱动。存档保存在当前用户的应用数据目录，与网页版记录独立。
